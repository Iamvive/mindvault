# Design Spec: Subtle Gradient Design System

This document specifies the architecture, tokens, guidelines, and rules for the **Subtle Gradient Design System**, Vivek's signature design language.

## 1. Overview & Principles

The Subtle Gradient Design System is characterized by high-contrast typography, desaturated gradient backdrops, a strict circular/oval shape vocabulary, and a singular, highly saturated primary accent color.

### Core Principles:
- **Desaturated Backdrops:** Content containers and page backgrounds should use soft, desaturated linear gradient washes (`--gradient-wash-*`) or warm neutral surfaces (`--sg-surface-card`) rather than flat colors or bright saturated gradients.
- **Accent Isolation:** `--sg-primary` (`#e60023` red) is the only fully saturated color. It should be used sparingly for primary actions, focus elements, active nav highlights, or key visual indicators.
- **Strict Typography:** A geometric sans-serif (Inter) is used globally. Monospace and serif fonts are forbidden for user interfaces. Negative tracking (letter-spacing) is applied to display tiers.
- **Oval/Pill Geometry:** Shapes should favor highly rounded corners:
  - `8px` for inputs/micro-elements
  - `16px` for standard cards/buttons
  - `32px` for large cards/modals
  - `9999px` (circular) for badges, chips, search bars, and avatar placeholders
- **Ambient Depth:** Shadows are avoided. Contrast is created using border dividers (`--sg-hairline`) and color shifts. The only shadow permitted is a single soft ambient shadow under overlays/modals.

We will append the following section:
```markdown
## Subtle Gradient Design System Constraints

Whenever generating UI styling, writing CSS, or styling frontend components:
1. **Typography:** Never use monospace, serif, or generic display fonts. Standard font family must be `Inter`, system-ui, sans-serif. Use negative tracking (e.g. `letter-spacing: -1.2px`) on display/large headings.
2. **Colors:** Use variables from the Subtle Gradient CSS. The only saturated accent color allowed is `--sg-primary` (`#e60023`). Avoid saturated greens, blues, or yellows unless explicitly requested.
3. **Surfaces:** Use desaturated washes (`--gradient-wash-*`) for card mockups, section backgrounds, or image placeholders.
4. **Rounding:** UI elements must be rounded. Use `16px` for standard cards/buttons, `32px` for major cards, and `9999px` for search bars, status chips, pill buttons, and avatars.
5. **Focus States:** Every button, input, or link must have a double-ring focus state on active/focus transitions using `box-shadow: var(--focus-ring)`.
```
